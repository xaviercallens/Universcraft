# UniversCraft: Implementation Plan & Roadmap

## Phase 1: Core Engine & T-Dual Rendering (Months 1-2)
**Objective**: Establish the ECS foundation and implement the scale-invariant ray marcher.
* **1.1 Engine Initialization**: Bootstrap the Rust workspace with `bevyengine/bevy`. Disable the standard 3D rendering pipeline.
* **1.2 WGPU Compute Shaders**: Write custom WGSL shaders for continuous SDF ray marching.
* **1.3 T-Duality LOD**: Inject the physics limit ($R_{eff} = \max(R, \alpha'/R)$). Implement the logic to halt ray evaluation at $\sqrt{\alpha'}$ and fallback to discrete K3 surface patterns to guarantee no GPU hangs.

## Phase 2: Topological Data Analysis & Organic Meshes (Months 3-4)
**Objective**: Move from point clouds to continuous, destructible 3D surfaces without voxel grids.
* **2.1 Point Cloud Generation**: Implement spatial particle density representations of the world.
* **2.2 Vietoris-Rips Filtration**: Integrate Rust TDA crates (e.g., `arclabs561/skel`) to compute homologies and link particles.
* **2.3 Surface Reconstruction**: Integrate `Splashsurf` to convert linked topological simplices into a dynamic, 1-Lipschitz continuous organic mesh in real-time.

## Phase 3: The Topological Lock (DONN) (Month 5)
**Objective**: Prevent visual chaos by harmonizing procedural generation.
* **3.1 ML Integration**: Integrate the `Burn` framework into the Bevy pipeline.
* **3.2 Deep Oscillatory Neural Networks**: Train and deploy a DONN to act on the point cloud.
* **3.3 Cymatic Terrain Alignment**: Force terrain particles to align to stationary waves, organically generating mountains (antinodes) and valleys (nodes) for highly optimized visual energy.

## Phase 4: Symplectic Fluid Dynamics (Months 6-7)
**Objective**: Robust, non-crashing fluid physics (water, wind, quantum fluids).
* **4.1 Solver Integration**: Fork and integrate `dimforge/salva` (Smoothed Particle Hydrodynamics).
* **4.2 Leray-Hopf Projection**: Apply the verified 3D Fourier state projection to enforce transversality (divergence-free states).
* **4.3 $l^2$ Decoupling & Enstrophy Cap**: Inject the topological bounds into the solver. Limit vorticity energy to ensure massive scale fluid interactions never cause a Navier-Stokes blow-up.

## Phase 5: AMCP Integration & Polish (Month 8)
**Objective**: Intelligent entities and network resilience.
* **5.1 AMCP Nodes**: Implement the Agent Mesh Communication Protocol for NPCs/Systems.
* **5.2 Environmental Reaction**: Hook agent pathfinding and behavior to the dynamic Persistence Landscape generated by the TDA pipeline.
* **5.3 Final Verification Pass**: Ensure all Lean 4 theorems (`DualScale.lean`, `TopoStability.lean`, `FourierStateZ3.lean`) perfectly map to Verus-checked Rust execution bounds.
